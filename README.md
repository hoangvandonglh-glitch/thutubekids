# 🌈 TheTubeKids - Safe & Fun Videos for Children

A beautiful, colorful video platform designed specifically for children — featuring curated, 100% safe and educational YouTube content.

## ✨ Features

- 🎬 **24+ Curated Safe Videos** — Hand-picked content for children aged 0-12
- 📂 **8 Categories** — Nursery Rhymes, Animals, Learning, Stories, Cartoons, Science, Music & Dance
- 🔍 **Live Search** — Search videos by title, channel, or description
- 📺 **In-app Video Player** — Watch videos in a beautiful modal with YouTube embed
- 🎨 **Gorgeous UI** — Colorful, animated, child-friendly design
- 🛡️ **100% Safe** — All content reviewed and approved for children
- 📱 **Fully Responsive** — Works on all devices
- ⚡ **Fast** — Built with Next.js 15 + Turbopack

## 🚀 Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. Push this project to GitHub
2. Go to [vercel.com](https://vercel.com) and create a new project
3. Import your GitHub repository
4. Click **Deploy** — Vercel automatically detects Next.js!

## 💻 Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
